개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 19일

본 애플리케이션(이하 "앱")은 운영자 본인의 YouTube 채널에 직접 제작한 영상을 업로드하기 위해 개인적으로 사용하는 도구입니다. 일반 사용자에게 서비스를 제공하지 않습니다.

1. 수집하는 정보

앱은 Google OAuth를 통해 다음 권한만 요청합니다.

  • https://www.googleapis.com/auth/youtube.upload — 운영자 본인 YouTube 채널에 동영상 업로드

앱은 이름, 이메일 주소, 연락처, 시청 기록 등 그 밖의 개인정보를 수집하지 않습니다.

2. 정보의 이용 목적

위 권한으로 발급된 인증 토큰은 운영자가 제작한 동영상을 운영자 본인 채널에 업로드하는 용도로만 사용합니다.

3. 보관 및 보호

  • 인증 토큰은 운영자 개인 컴퓨터에만 저장되며, 외부 서버로 전송하거나 공유하지 않습니다.
  • 운영자는 언제든지 Google 계정 설정(https://myaccount.google.com/permissions)에서 앱의 접근 권한을 철회할 수 있으며, 철회 시 토큰은 더 이상 사용할 수 없습니다.

4. 제3자 제공

앱은 어떠한 정보도 제3자에게 판매, 제공, 공유하지 않습니다.

5. Google API 서비스 이용

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관(https://www.youtube.com/t/terms)과 Google 개인정보처리방침(https://policies.google.com/privacy)이 함께 적용됩니다.

앱이 Google API로부터 받은 정보의 사용은 Google API Services User Data Policy 및 Limited Use 요건을 준수합니다.
